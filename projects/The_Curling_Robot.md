# The Curling Robot
## Description
<img 
  src="../images/DR20.jpeg" 
  alt="Final Presentation"
  style="float: right; width: 250px; margin: 40px 10px 24px 32px; border-radius: 8px;">

Our team designed, built, and programmed an autonomous robot that orients itself, navigates to the optimal shooting position, and launches pucks toward the center scoring rings using a flywheel-based mechanism.

My Contributions: 
- Designed the electrical schematic and wired the physical circuit for the motor systems, including motor drivers for the     drivetrain, flywheels, and puck-feeding stepper motor
- Wrote the finite state machine and test scripts for robot movement, flywheel control, and puck feeding
- Fabricated the robot chassis
