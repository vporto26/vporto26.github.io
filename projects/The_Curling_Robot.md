

# The Curling Robot
## Description

Our team designed, built, and programmed an autonomous robot that orients itself, navigates to the optimal shooting position, and launches pucks toward the center scoring rings using a flywheel-based mechanism.

My Contributions: 
- Designed the electrical schematic and wired the physical circuit for the motor systems, including motor drivers for the    drivetrain, flywheel, and puck-feeding stepper motor
- Programmed motor speed control using PWM on an Arduino, and wrote the finite state machine and test scripts for robot      movement, flywheel control, and puck feeding
- Fabricated the robot chassis
